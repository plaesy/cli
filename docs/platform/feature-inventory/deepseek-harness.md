## Bukti plaesy untuk baris non-belum

Setiap baris `sebagian` di atas hanya sebagian dari perilaku DSH. Cakupannya dibatasi sebagai berikut.

- DSH-047 (`openai-completions` dengan loop tool): `crates/plaesy/adapter/model-openai-tools/src/lib.rs` dan `crates/plaesy/adapter/model-openai-tools/src/openai_test.rs` (tes: argumen tool call di-parse dan hasil dikirim dengan `tool_call_id`, jawaban biasa tanpa tool, argumen tidak valid menjadi objek kosong, kunci Bearer dari env var, galat bila env var hilang, loop berhenti di batas putaran). Cakupan plaesy: loop tool untuk klien ACP, bukan konfigurasi provider DSH.
- DSH-048 (`anthropic-messages`): `crates/plaesy/adapter/model-anthropic-tools/src/lib.rs` dan `anthropic_test.rs` (tes: `tool_use` dijalankan dan hasil dikembalikan sebagai `tool_result`, kunci hilang berhenti sebelum permintaan, batas putaran, tool tidak dikenal tidak dijalankan). Catatan: header crate menyatakan ini opt-in dan melanggar aturan offline di `CLAUDE.md`.
- DSH-045 (ulang otomatis permintaan model): `crates/plaesy/support/loop/src/delegate_test.rs` (tes: galat transien berpindah ke penyedia berikutnya, galat terminal menghentikan rantai dan menyebut setiap percobaan). Cakupan plaesy hanya berpindah penyedia. Tidak ada backoff, tidak ada `retryPolicy`, dan tidak ada ulang pada penyedia yang sama. Karena itu hanya bagian ini yang dihitung sebagian.
- DSH-073 (perintah latar belakang): `crates/plaesy/support/loop/src/loop_run/jobs.rs` dan `jobs_test.rs` (tes: job selesai punya exit code dan output di berkas; job tanpa berkas exit dianggap belum selesai, bukan galat). Cakupan plaesy hanya di sisi proses dan berkas, belum ada tool `job_output` yang dapat dipanggil model. Tidak ada tes plaesy untuk `job_kill` atau batas waktu tunggu, sehingga DSH-075 tetap `belum`.
- DSH-133 (ACP stdio): `crates/plaesy/interface/cli/src/cli/acp.rs` dan `crates/plaesy/interface/acp/src/acp_test.rs` (melayani ACP v1 lewat stdio, prompt dijawab oleh satu penyedia dari konfigurasi). Cakupan lebih sempit dari `dsh --profile acp`: tidak ada profil, tidak ada HMR, dan tidak ada log sesi yang bisa dilanjutkan.

## Penelusuran yang tidak dihitung sebagai bukti

Kata kunci berikut cocok di `crates/` tetapi perilakunya berbeda dari fitur DSH, sehingga baris DSH terkait tetap `belum`.

- `interface/mcp`: server MCP untuk dokumen (`document_get`, `document_put`, `document_list`, `document_delete`). Bukan klien MCP. Tidak menjadi bukti DSH-121 sampai DSH-125.
- `adapter/memory/src/schedule/mod.rs`: menjalankan job pemeliharaan memori (`index`, `hygiene`, `missing`, `curate`) pada interval tetap. Bukan pengingat yang dikirim ke percakapan. Tidak menjadi bukti DSH-106 sampai DSH-116.
- `adapter/runtime/src/runtime/native.rs`: adapter proses dengan allowlist dan batas waktu yang membunuh proses. Dokumennya menyebut diri sendiri "bukan sandbox". Di DSH, timeout justru membuat perintah menjadi background job, bukan dibunuh. Tidak menjadi bukti DSH-094 sampai DSH-096 maupun DSH-074.
- `interface/cli/src/cli/sessions.rs`: status sesi yang dilaporkan sendiri per proyek. Bukan pelanjutan sesi (`--session-id`). Tidak menjadi bukti DSH-051 atau DSH-052.
- `interface/cli/src/cli/delegate.rs`: satu prompt ke penyedia yang dikonfigurasi, tanpa tool dan tanpa sesi tersimpan. Tidak menjadi bukti DSH-052.
- `domain/identity/src/secrets`: penyamaran nilai rahasia di log dan ekspor. Berbeda dari penyamaran di Web UI (DSH-141). Tidak menjadi bukti DSH-141.
- `adapter/relay`: antrean SQLite lokal untuk komunikasi antar-agen. Bukan subagent DSH (DSH-081 sampai DSH-086).
