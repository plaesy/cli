## Tidak bisa diverifikasi dari sumber

Daftar berikut berisi klaim yang tidak dapat dipastikan dari dokumentasi dan kode pada commit pinned. Penyebabnya adalah butuh build, perangkat, akun, layanan eksternal, atau tidak ditemukan padanannya di kode.

- Onion-skin pada diff gambar: kata kunci `onion` tidak ditemukan di `src/`.
- Atribusi AI per baris di diff (`docs/site/content/docs/review/attribution.mdx`): tidak ditemukan implementasi dengan nama yang diklaim dokumen. Belum ditelusuri menyeluruh.
- Design Mode: nama `designMode` tidak ditemukan. Implementasi yang mirip ada di `src/main/browser/element-grab/`, tetapi belum dicocokkan dengan seluruh klaim dokumen (konteks elemen, gaya terhitung, dan source map).
- Tombol Share as artifact dan setelan Ask Before Deleting Artifacts: nama setelan tidak ditemukan di `src/`. Penghapusan artifact belum ditelusuri.
- Batas penyalinan `.worktreeinclude` 2 GiB dan 50.000 entri, serta batas orca.yaml (64 KiB per field, 256 defaultTabs, 100 sharedDirectories): nilai tidak ditemukan di berkas yang dibaca. Belum ditelusuri ke berkas lain.
- Hibernasi dengan default 30 menit dan rentang 1 menit sampai 24 jam: hanya ditemukan jejak di `src/renderer/src/components/settings/advanced/ExperimentalPane.tsx`; nilai default belum dicocokkan.
- Perilaku UI dan interaksi (drag tab, popover, pinned boundary, filter sidebar, kartu dashboard): hanya dari dokumen. Aplikasi tidak dijalankan.
- Aplikasi mobile (iOS, Android), pairing fisik, push APNs dan FCM: membutuhkan build dan perangkat. Folder `mobile/` ada di repo, tetapi tidak dijalankan.
- Relay Orca (`relay.onorca.dev`), Cloud VM dengan penyedia eksternal (Vercel Sandbox, Fly, Modal), dan folder `cloud/`: bergantung layanan dan akun. Tidak diuji.
- Isi dan retensi telemetri (PostHog, Amerika Serikat) serta daftar properti yang dikirim: hanya gating environment variable yang dicek.
- Keamanan token (keychain OS), Kerberos, dan FIDO2: bergantung OS dan perangkat keras.
- Akurasi dikte suara dan model unduhan: bergantung model dan perangkat.
- Computer use dan emulator (Accessibility, adb, serve-sim): membutuhkan izin OS dan perangkat.
- Instalasi dan pembaruan (cask, winget, AppImage, paket .deb dan .rpm, arsip orca-server beserta checksum): membutuhkan rilis dan jaringan.
- Perilaku layanan eksternal (GitHub, GitLab, Bitbucket, Azure DevOps, Gitea, Linear, Jira, endpoint usage provider, dan batas rate): bergantung provider.
