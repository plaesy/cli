# Inventaris fitur FigCraft

- **Produk:** FigCraft, editor desain antarmuka open source (`storytold/figcraft`), dibangun dengan Rust.
- **Sumber pinned:** commit `e1883565479f3c763488fe0d7a149fafee33ebb9` (tanggal commit 2026-11-17, digabung dari PR #2420).
- **Tanggal inventaris:** 2026-11-22.
- **Lingkup:** kanvas, seleksi, layer, vektor, paint dan efek, teks, auto layout, komponen dan variant, style dan variabel (token), ekspor dan impor, prototipe, Dev Mode, kolaborasi, dan platform. Fokus utama: kanvas, komponen, variant, auto layout, token, ekspor, dan kolaborasi.
- **Metode:** setiap baris adalah satu perilaku yang diuji, diambil dari tabel "Rules from the documentation" dan "Features" pada dokumen paritas di commit pinned, atau dari README. Tautan menunjuk ke baris sumber pada commit itu. Nama tes yang dikutip dokumen dicocokkan dengan kode pada commit pinned: 473 dari 477 identifier ditemukan; yang tidak ditemukan dicatat di bagian batasan. Pencocokan hanya memeriksa keberadaan nama, bukan hasil tes.
- **Status di plaesy:** `belum` kecuali ada kode di `crates/` beserta tes. `sebagian` dipakai bila ada kode dan tes untuk sebagian perilaku. Tidak ada baris berstatus `ada`. Bukti setiap status `sebagian` tercantum di bawah tabel.
