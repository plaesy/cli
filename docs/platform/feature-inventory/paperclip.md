- Status di plaesy adalah `belum` kecuali ada kode di `crates/` beserta tes yang memeriksa perilaku itu. Status `sebagian` dipakai jika cakupannya parsial. Pemetaannya ada di bagian "Pemetaan status plaesy". Tidak ada baris `ada`.

## Ketidaksesuaian dokumen dan kode

`doc/TASKS.md` menyatakan dirinya model target: "some of this is already implemented, some is aspirational". Empat contoh dicek di kode pada commit pinned:

- Prioritas: dokumen menyebut skala 0 sampai 4. Kode (`packages/shared/src/constants.ts`, baris 223) memakai `critical`, `high`, `medium`, dan `low`. Default kolom `priority` adalah `"medium"`.
- Status: dokumen memakai workflow state per tim. Kode memakai daftar tetap `ISSUE_STATUSES` (`backlog`, `todo`, `in_progress`, `in_review`, `done`, `blocked`, `cancelled`).
- Relasi: dokumen menyebut empat tipe. Tabel `issue_relations` hanya memiliki tipe `"blocks"` (`packages/db/src/schema/issue_relations.ts`, baris 13).
- Milestone: tidak ada tabel milestone di `packages/db/src/schema/`.

Baris PPC-204 sampai PPC-211 mengikuti dokumen target, bukan kode. Jangan dipakai sebagai acuan perilaku tanpa membaca kode.
