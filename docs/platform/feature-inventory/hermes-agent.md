# Inventaris fitur Hermes Agent

Tanggal: 2026-11-22. Repo sumber: https://github.com/NousResearch/hermes-agent. Commit pinned: `40d1e95f37e409f9f618f32c170661c66b86a4f4` (committer date 2026-11-17).

Cakupan: seluruh perilaku produk yang didokumentasikan di `website/docs/` pada commit pinned (user-guide, reference, getting-started, integrations, developer-guide), ditambah tool, slash command, dan subcommand CLI yang terdaftar di referensi. Jumlah baris fitur: 608. Skill opsional (141 SKILL.md), katalog plugin (2.383 entri), dan katalog MCP opsional (66 entri) dicatat sebagai mekanisme, bukan per item. Platform pesan dicatat per adapter.

## Metode

- Sumber dokumen: sparse checkout `website/docs/` (user-guide, reference, getting-started, integrations, developer-guide), `README.md`, dan `toolsets.py` pada commit pinned. Daftar berkas kode diambil dari pohon git pada commit yang sama (26.197 berkas).
- Setiap baris berasal dari heading, tabel, atau paragraf dokumen pada commit pinned. Klaim pemasaran di README tidak dijadikan baris kecuali didukung dokumen fitur.
- Verifikasi kode Hermes: 75 nama tool dari referensi ditemukan sebagai string literal di `tools/`, `plugins/`, atau `agent/`. Adapter platform ada di `plugins/platforms/` (26 direktori). Slash command dan subcommand CLI yang diperiksa ditemukan di `hermes_cli/`. Perilaku tiap tool tidak dijalankan.
- Status plaesy: dicek dengan grep di `crates/` dan dengan membaca modul serta berkas tes terkait (`*_test.rs`, `tests/`). Baris `sebagian` hanya diberikan bila ada kode dan tes untuk perilaku yang setara. Kemiripan nama modul saja tidak cukup. Tidak ada baris `ada`, karena tidak ada perilaku Hermes yang sudah setara penuh di plaesy.

Legenda Status di plaesy: `belum` = tidak ada padanan perilaku; `sebagian` = ada kode dan tes untuk sebagian perilaku, dengan batas dijelaskan di bagian Bukti; `ada` = ada kode dan tes untuk seluruh perilaku; `di luar batas` = tidak termasuk subset chat, dengan alasan dan persetujuan pemilik.

## Bukti status plaesy (baris `sebagian`)

Setiap baris `sebagian` memakai bukti berikut. Batas kesetaraan dicantumkan agar status tidak dibaca lebih luas dari kenyataannya. Path relatif terhadap `crates/plaesy/`.

- Penulisan catatan lewat MCP (`memory_remember`, hanya catatan baru): `adapter/memory/src/mcp/mod.rs`, `mcp/mcp_test.rs`. Tidak ada MEMORY.md atau USER.md yang dimuat ke prompt (HRM-041).
- Pemindaian isi catatan terhadap kredensial: `adapter/memory/src/hygiene/secrets.rs`, `hygiene/hygiene_test.rs`. Hanya pola rahasia; Hermes juga memindai pola injeksi dan eksfiltrasi (HRM-267).
- Rantai provider dan pemakaian per provider serta per rantai: `support/loop/src/delegate/providers.rs` (aturan status untuk rantai), `providers_test.rs`; `support/loop/src/delegate/usage.rs`, `usage_test.rs`. Rantai dipilih lewat konfigurasi; tidak ada perintah `hermes fallback` atau subagen (HRM-196, HRM-320).
- Satu prompt ke provider yang dikonfigurasi (non-interaktif): CLI `interface/cli/src/cli/delegate.rs`. Tidak ada tool dan tidak ada sesi (HRM-192).
- Penyedia OpenAI-compatible dengan tool calls: `adapter/model-openai-tools/src/lib.rs`, `openai_test.rs`; `support/loop/src/delegate/providers.rs` (endpoint chat/completions) (HRM-325, HRM-589). Loop agen (HRM-588) memakai jalur tool-calling yang sama.
- Penyedia Anthropic: `adapter/model-anthropic-tools/src/anthropic_test.rs` (HRM-326). Penyedia Ollama lokal: `adapter/model-ollama/src/ollama_test.rs` (HRM-327, HRM-473). llama.cpp dan LM Studio tidak punya adapter.
- Loop (`plaesy loop`): `support/loop/src/loop_run/completion_test.rs`, `driver_test.rs`, `stophook_test.rs`; CLI `interface/cli/src/cli/loop_cmd.rs`. Berhenti pada kondisi atau batas iterasi (HRM-364). Tidak ada mode interval dan tidak ada juri LLM seperti `/goal` (HRM-096 belum).
- Papan tugas berbasis folder (`backlog`, `todo`, `doing`, `done`, `blocked`), klaim dengan kunci penasihat di `.claims/`, dan perintah `tasks validate` yang menjalankan `contracts.json` sebelum task pindah ke `done`: `support/tasks/src/tasks/mod.rs`, `claim_test.rs`, `contracts_test.rs`, `check_test.rs`; CLI `interface/cli/src/cli/tasks.rs` (HRM-218, HRM-428, HRM-429). Tidak ada dispatcher, worker, atau dependensi yang menahan task. Kontrak PR Hermes (HRM-432) belum punya padanan: kontrak plaesy menjalankan perintah, tidak mengikat URL PR.
- Server MCP plaesy: `interface/mcp/src/lib.rs`, `interface/mcp/src/mcp_test.rs`. Mengekspos empat tool dokumen (`document_get`, `document_put`, `document_list`, `document_delete`), bukan tool percakapan (HRM-243, HRM-395).
- Server ACP stdio: `interface/acp/src/lib.rs`, `interface/acp/src/acp_test.rs`; CLI `interface/cli/src/cli/acp.rs` (HRM-241, HRM-399). Parameter `mcpServers` hanya divalidasi tipenya; server MCP dari editor belum dipakai (HRM-400 belum).
- Pembuatan gambar lewat OpenAI (`gpt-image-1`): `support/common/src/imagegen.rs`, `imagegen_test.rs`; CLI `interface/cli/src/cli/images.rs` (HRM-417). Satu backend.
- Pencarian web lewat backend Exa di CLI `reach`: `support/analysis/src/reach/adapters/social.rs`, `social_test.rs`; `interface/cli/src/cli/reach.rs` (HRM-422). Bukan tool agen.
- Allowlist persetujuan (`ApprovalStore`: approve, revoke, is_approved): `domain/workflow/src/policy/approvals.rs`, `approvals_test.rs` (HRM-453). Belum terhubung ke binary `plaesy` (CLAUDE.md, bagian Architecture). Mode manual, smart, dan off belum ada (HRM-452 belum).
- Plugin hanya dimuat bila setiap kapabilitasnya diberi izin: `plugin/sdk/src/lib.rs`, `plugin/sdk/src/sdk_test.rs` (HRM-378). Analog dengan daftar izin plugin Hermes, bukan sistem plugin lengkap.
- Pemasangan, pembaruan (ganti biner dengan build yang lebih baru), dan pelepasan instalasi (HRM-260, HRM-261, HRM-477, HRM-478, HRM-601): `support/common/src/installer.rs`, `installer_test.rs`, `installer/path_cleanup.rs`, `plaesy/tests/install_e2e.rs`. Pemasangan ke `%LOCALAPPDATA%\Plaesy\bin`; `uninstall` mempertahankan data pengguna menurut teks bantuan CLI. Tidak ada pembaruan dari rilis.

Baris yang diberi status `belum` walaupun ada modul terkait di `crates/` (misalnya `doctor`, `onboard`, dan `schedule` untuk prompt agen) tidak punya tes yang mencakup perilaku Hermes, sehingga tidak dihitung `sebagian`.
