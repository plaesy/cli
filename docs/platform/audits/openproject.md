## Coverage, boundaries, unknowns

Inspected evidence here is a synthesis of existing bounded repository records: README and user/admin/API indexes, selected project/workspace and parent-selector source/specs, selected work-package API/source assertions (WP-001–046), memberships/roles (MEMBER-001–024 and ROLE-001), query/view slices, selected time-entry and adjacent API evidence. All cited request assertions were read only, not executed. The existing inventory says no usable Ruby/Bundler runtime for the prior audit; this task did not run OpenProject tests. No isolated runtime/test environment or prerequisites were established here; tests are **not run**, not a product failure.

Uninspected/incomplete: exhaustive maintained docs against the pin; complete module inventory and edition applicability; full project/workspace PATCH/DELETE shared examples; all work-package schemas/operations and side effects; complete agile, scheduling, reporting, time/cost, permission, integrations, migration, backup/restore, upgrade and recovery workflows; database/runtime behavior; and migration round trips. User identity and cross-project/tenant boundaries are not fully established. Edition-specific claims are limited to selected source assertions (for example selected feature-flag/EE-gated cases) and do not establish a Community/Enterprise feature matrix. Unknown remains unknown; no absence or parity claim.
